- **Outputs, text, figures and data:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/), unless restricted by third parties.
- **Published replication code:** [MIT licence](https://opensource.org/license/mit), unless stated otherwise. Unpublished code is available from CEE on request.
- **Source restrictions:** where an original data source imposes its own terms, those terms prevail. See the [data catalogue](../observatorio/catalogo/).

## How to cite

Each publication and dashboard provides a "How to cite" block in ABNT, BibTeX and RIS formats, plus a DOI where one exists. When citing Observatory data, please state the edition and the extraction date.

Content is provided without warranty of any kind. Errors are corrected through public, dated errata.
