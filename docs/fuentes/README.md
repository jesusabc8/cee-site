# Fontes

O conteúdo institucional do sítio deriva da **Proposta institucional do CEE, versão 3.0 (19/10/2026)**,
documento de trabalho ainda não aprovado. O arquivo (`CEE_PUCMinas_Proposta_v3.0.docx`) **não é versionado
neste repositório público** até a apresentação à coordenação do curso (ver `docs/DECISIONES.md`, ADR-005).
Quem mantém o sítio deve obtê-lo com a Coordenação Executiva e colocá-lo nesta pasta localmente.

As seções da Proposta usadas em cada página são citadas no cabeçalho dos arquivos de conteúdo (`src/content/`).
